📄 Abstract

I evaluate the market reaction to Microsoft's $68.7B acquisition of Activision Blizzard announced on January 18, 2022. Using an estimation window (July 2021 – January 10, 2022) to fit expected returns and an event window (January 11–28, 2022) to measure impacts, I compute abnormal returns (AR) and cumulative abnormal returns (CAR). A two-sample t-test shows a significant mean shift; CAPM and a sector-adjusted multifactor model confirm significance. CAR increases approximately +29% post-announcement.

📋 Data

  • Sources: Yahoo Finance daily prices for ATVI and S&P 500
  • Series: Close prices and computed daily log/percent returns
  • Prep: Cleaned dates, aligned trading days, computed returns in R and Excel
📐 Returns aren't perfectly normal, but with n ≈ 144 the t-test is robust; the Central Limit Theorem supports inference on mean differences.

⚙️ Methodology

The study follows a standard event study framework in four steps: fit expected returns on the estimation window, compute abnormal returns on event days, accumulate to CAR, and test for significance.

CAPM:  ri − rf = α + β(rm − rf) + ε
Multifactor:  CAPM + β2(ESPO) — sector index for gaming/esports exposure
  • t-test: Mean comparison between estimation and event window returns
  • CAPM: Single-factor model using S&P 500 as market proxy
  • Multifactor: Adds ESPO sector index for gaming/esports exposure

📊 Results

All three approaches confirm significant abnormal returns around the announcement date. The CAR chart shows a clear structural break at Day 0 with returns jumping approximately +29%.

🔒 Robustness

  • Winsorizing: Trimming at 1%/99% leaves inference unchanged
  • Return type: Percent vs. log returns yield similar CAR shape
  • Window variation: Alternative windows (±3, ±5 days) preserve significance
