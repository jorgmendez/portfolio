Customer Churn Analysis

Sep 2025 Excel Pivot Tables Slicers KPI Dashboard

Explored churn patterns in a telco-style dataset using only Excel. Built an interactive workbook with KPIs, drill-downs, and slicers so a business user can filter by plan, region, and usage to see what drives customer losses — no Power BI or code required.

📋 Dataset

  • Rows: Customers with demographics, plan features, usage metrics, and churn flag
  • Targets: Churned vs. retained, churn reason text, churn rate %
  • Prep in Excel: Cleaned headers, created helper columns (age bands, usage bands), set up tables for pivots
💡 Everything stays native to Excel so analysts without BI tools can filter and slice the same workbook.

⚙️ Approach

  • Pivots: Churn rate by reason, demographics, age group, state, and data usage bands
  • Visuals: Bar chart for ranked churn reasons; doughnut charts for competitor vs. other; combo chart for age bands; heatmap for churn by state
  • Interactivity: Slicers wired to all pivots (e.g., intl plan, device type) so the dashboard responds instantly
  • Formatting: Data bars and color scales highlight the highest-risk segments
